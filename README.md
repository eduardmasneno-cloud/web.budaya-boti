# Jelajah Budaya NTT — Suku Boti

Website statis untuk dokumentasi budaya Suku Boti.

## Struktur
- `index.html` — halaman utama
- `main.js` — navigasi/interaksi
- `style.css` — stylesheet pendukung
- `laporan/Laporan-Budaya-Suku-Boti.pdf` — laporan yang dapat dibuka dari menu **Laporan**

## GitHub Pages
1. Upload seluruh isi folder ini ke repository GitHub.
2. Buka **Settings → Pages**.
3. Pilih **Deploy from a branch**.
4. Pilih branch utama (misalnya `main`) dan folder `/ (root)`.
5. Simpan. GitHub Pages akan menggunakan `index.html` sebagai halaman utama.

Laporan PDF menggunakan path relatif sehingga dapat dibuka langsung setelah situs dipublikasikan.
